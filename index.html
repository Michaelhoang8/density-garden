Neighborhood-distance profile

Sorted distance to the minimum-points-th nearest observation, including itself. A point is core exactly when this distance is at most ε. When fewer observations exist, the distance is unavailable.

How to read a border

Core points have at least the minimum number of observations inside the inclusive radius, counting themselves. Connected core points form clusters. A non-core point touching a core cluster is a border point; a point touching none is noise.

A border point can touch several core components without connecting them. We expose all candidate clusters and assign the lowest cluster number. Numbers follow the first core point in input order. Reordering can therefore change an ambiguous border assignment without changing the core components.

Duplicate coordinates are separate observations. Euclidean distance is applied directly to these synthetic integer coordinates; this is not geographic distance or automatic feature scaling. Density parameters should reflect the data, and there is no universal best radius.
